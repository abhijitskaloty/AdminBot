# AdminBot

> **Note:** This repository is a fork/mirror of my original project from my previous account (@abhijitsinghkaloty) that I no longer have access to.

A moderation-focused bot built with **Node.js** and **discord.js**.  
Designed to make server moderation faster while also providing a few utility/fun commands.

## Features

### Moderation (admin-only)
- Kick / ban
- Mute / unmute
- Purge (bulk delete messages)
- Slowmode
- Nickname management

### Utility / fun
- Welcome / hello
- Avatar
- Ping (bot latency)
- Whois (user info)
- Members (server/member info)

## Tech Stack
- JavaScript (Node.js)
- discord.js
